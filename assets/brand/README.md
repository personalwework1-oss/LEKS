# Знак LEKS

Векторная перерисовка фирменного знака (без надписи LEKS — в приложении используется только знак).

| Файл | Назначение |
| --- | --- |
| `leks-mark.svg` | Знак цветом текста (`currentColor`), вырезы прозрачные — для экранов приложения |
| `leks-mark-light.svg` | Светлый знак `#F0F0F0` для тёмного фона |
| `app-icon.svg`, `app-icon-1024.png` | Иконка приложения 1024×1024: светлый знак на `#141416` |

Совпадение с исходным логотипом по площади — 97 %.
